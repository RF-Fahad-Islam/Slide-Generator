### Theme System

All components accept `appTheme?: 'dark' | 'light'` prop and derive `const isAppLight = appTheme === 'light'`.
Conditional classes use ternary: `isAppLight ? '[light-class]' : '[dark-class]'`.
**Do NOT use Tailwind `dark:` prefix** — use the prop-based `isAppLight` pattern exclusively.

**CRITICAL — `glass-card-fatty` Tailwind v4 gotcha:** The `.glass-card-fatty*` classes are defined as unlayered CSS in `index.css`. In Tailwind v4, unlayered rules have higher specificity than `@layer utilities`. Therefore:
- Putting `glass-card-fatty` (dark) in the base className and adding `bg-white/95` in the light branch → the DARK background wins → light cards render grey.
- Correct pattern: put the glass class itself inside the `isAppLight` ternary, e.g.
  ```jsx
  className={`${isAppLight ? 'glass-card-fatty-light' : 'glass-card-fatty'} p-6 ... ${
    isAppLight ? 'border-slate-200' : 'bg-slate-900/80 border-slate-800'
  }`}
  ```
- Same trap applies in reverse: `glass-card-fatty` in dark mode will override `bg-slate-950/85` AND its built-in `border: 1px solid rgba(255,255,255,0.08)` will override `border-slate-800/80`. For dark mode, either use `glass-card-fatty` alone (accept the white-ish border) or use `bg-slate-900/80 border-slate-800` without the glass class.

### `MathHelperButton` — `src/components/math/MathHelperButton.tsx`
- **Purpose:** floating "fx" (`Sigma` icon) helper attached to any text field that can contain inline `$LaTeX$` (SSC/HSC math/physics/chemistry). Opens a popover with (1) a **Live Preview** section that renders the field's current value through the existing `MathText` component so raw LaTeX code can stay hidden while editing, and (2) a category-tabbed **snippet palette** (`src/components/math/mathSnippets.ts`: Algebra & Fractions / Physics / Chemistry / Greek Letters / Calculus / SSC/HSC Common) whose buttons insert ready-to-edit LaTeX (e.g. `$\frac{}{}$`) at the field's cursor via `src/utils/cursorInsert.ts` (`insertSnippetAtCursor`), landing the cursor inside the first empty `{}` placeholder. No new dependency — reuses the already-installed `katex` package through `MathText`.
- **Props:** `value`, `onChange(newValue)`, `inputRef` (ref to the underlying `<input>`/`<textarea>`), `isAppLight`, optional `label` (for the button title) and `className`.
- **Positioning:** popover is `position: fixed`, computed from the button's `getBoundingClientRect()` on open and clamped to the viewport (flips above the button if it would overflow the bottom); closes on outside click or Escape.
- **Wiring:** caller wraps its field in a `flex`/`relative` row and renders `<MathHelperButton>` beside it, passing a `useRef` for that field. Used in `EditQuestionModal.tsx` (stem + 4 options), `EditableMCQCard.tsx` (stem + options, both `mode="select"` and `"approved"` edit states), `SlideTextBoxPanel.tsx` (the "Text Content / Custom Text" textarea), and `ManualEditor.tsx` (the raw bulk-paste textarea). Not wired into `AddQuestionsModal.tsx` — that component has no text fields, it's a 3-card router to the other tools.

### `BackgroundImageEditor` — `src/components/BackgroundImageEditor.tsx`
- **Purpose:** reusable canvas-based modal for **Resize · Crop · Fit** of any uploaded background image. Opened right after a bg image is selected in `DeckSettings` (bg upload) and `SocialPostGenerator` (custom canvas bg upload). No new dependencies (uses `document.createElement('canvas')` + `drawImage`).
- **Shell:** fixed overlay `z-[9999]` (`bg-black/50` light / `bg-black/85` dark, `backdrop-blur-sm`), `max-w-5xl max-h-[92vh] rounded-3xl shadow-2xl overflow-hidden` card. Header: amber gradient `Scissors` tile (`p-2.5 rounded-2xl from-amber-500 to-amber-300`) + "Resize · Crop · Fit Background" (`text-sm font-black uppercase`) + subtitle + ✕ close. Body `grid grid-cols-1 lg:grid-cols-5 gap-5 p-5 overflow-y-auto` — crop stage `lg:col-span-3`, controls `lg:col-span-2`. Footer: Cancel + amber "Apply Background" (`Check`).
- **Crop stage:** `relative w-full h-[320px] sm:h-[400px] lg:h-[440px] rounded-2xl overflow-hidden touch-none select-none` (`bg-slate-900/90 border-slate-300` light / `bg-slate-950 border-slate-800` dark). Image absolutely positioned at `contain` scale (`width/height/left/top` from `dispW/dispH/offX/offY`). **Crop frame** (`absolute border-2 border-amber-400`) rendered only in `fit === 'cover'`: 4 dim regions (`bg-black/55`) outside the box, rule-of-thirds guides (`bg-white/25` 1px vertical/horizontal at ⅓/⅔), 4 corner handles (`w-3 h-3 rounded-sm bg-amber-400 border border-slate-950 cursor-nwse-resize/nesw-resize`), live `W × Hpx` mono readout (`bg-black/60 text-amber-300`). Drag anywhere = move (`applyDrag mode 'move'`), corner handles = aspect-locked resize. Non-cover fits show "Full image · Contain/Stretch" label. Pointer events use `setPointerCapture`, coords converted via `toImgCoords` (client px → natural image px through the contain scale).
- **Controls:** (1) **Aspect Ratio** `p-4 rounded-2xl border` card — `grid grid-cols-2 gap-2` chips (`Maximize2` amber label); active `bg-amber-500 text-slate-950 border-amber-400 shadow-md font-black`. (2) **Fit Mode** `grid grid-cols-3 gap-2` — Cover "Fill + crop" / Contain "Whole image" / Stretch "Distort"; active amber. (3) **Output Size** `flex flex-wrap gap-2` presets Original/720/1080/1920/4096 + live `→ W × Hpx · ratio` mono readout.
- **Output:** `handleApply` creates a canvas at `outputW×outputH` (preset width or natural crop width, height = width/ratio) and `drawImage`s the region — cover = cropped region, contain = whole image fitted (letterboxed), stretch = whole image stretched. `toDataURL('image/jpeg', 0.92)` → `BgImageEditorResult { dataUrl, fit, ratioId, width, height }`.
- **Props:** `open`, `imageUrl`, `isAppLight`, `ratios: BgRatioOption[]` (`{ id, label, value (w/h), hint }`), `defaultRatioId`, `onClose`, `onApply(result)`.
- **Wiring:** `DeckSettings` opens on bg upload (`handleBgEditorApply` → `handlePatch({ bgImageUrl, bgPreset:'custom', bgImageFit })`; ratios 16:9/4:3/1:1/9:16, default 16:9; "Re-edit Image" reopens with the current URL; Clear resets fit). `SocialPostGenerator` opens on custom-bg upload (ratios 1:1/4:5/9:16, default = current aspect) and persists `bgImageFit` in `CustomPostDesign`/`StoredPostDesign`; "Re-edit" button on the active-bg card.
- **Fit rendering contract:** all renderers map `bgImageFit` → `backgroundSize`: `cover` → `'cover'`, `contain` → `'contain'`, `stretch` → `'100% 100%'`, with `backgroundPosition: 'center'` + `backgroundRepeat: 'no-repeat'`. Applied in `SlideCanvas`, `DeckSettings` preview, `DeckQuestionPaperModal`, `QuestionBankPdfModal` (was hardcoded `bg-cover bg-center`), `ClassicQuizCard`, `QuizTimeCard`, and the `SocialPostGenerator` custom canvas. `BgImageFit` type lives in `types.ts`; `DeckConfig.bgImageFit?` + `templatePresets` snapshot capture it.
